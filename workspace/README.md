# Local workspace

This directory is created and managed by `rigcal`. It contains regenerable
preparation/method caches, resumable temporary transactions, saved queue
snapshots, and visualization sessions. Its generated contents are ignored by
Git and are not part of the submission.

Use **Cleanup storage** in the application instead of removing files from an
active `temporary_runs/` transaction manually. Published scientific results
live under `results/`, not here.
