# OBJ Mesh Assets

This folder contains the OBJ/MTL representation and related texture images for the BeIntelli bus model.

Typical content:

```text
beintelli_erklarbus.obj
beintelli_erklarbus.mtl
*.png
```

Keep `.obj`, `.mtl` and referenced texture files together. If any material or texture filename changes, update the `.mtl` references as well.
