AP03 FINAL RESULT — Single Ref14 vs Multi-ArUco Scale Registration
==================================================================

Method:
COLMAP reconstructs static and moving cameras from natural image features.
The reconstruction has arbitrary scale and coordinate frame.
ArUco markers are used only after COLMAP for metric Sim(3) scale/frame registration.

Compared variants:
- AP03a Single Ref14 Sim(3): uses only marker 14 as metric reference.
- AP03b Multi-ArUco Sim(3): uses all visible ArUco markers with the known marker layout.

Important:
- COLMAP itself remains targetless in both variants.
- Multi-ArUco is not used during COLMAP reconstruction.
- Multi-ArUco is used only for post-hoc metric registration.
- GT camera poses are used only for final error evaluation.
- AP03b is the current main AP03 result because it is more accurate and more robust.

Interpretation:
Multi-ArUco registration strongly improves AP03 because the Sim(3) scale/frame estimation is constrained by all visible marker corners instead of only one marker.
This reduces sensitivity to noise in the single reference marker triangulation and produces a more stable metric registration.
