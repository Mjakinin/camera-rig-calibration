AP03 SINGLE/MULTI SPLIT POLICY
==============================

Future final comparison tables must split AP03 into:

1) AP03-SINGLE-REF14
   Targetless COLMAP reconstruction followed by single Ref14 marker metric registration.
   ArUco is used only after COLMAP reconstruction.
   GT is used only for final evaluation.

2) AP03-MULTI-ARUCO
   Targetless COLMAP reconstruction followed by Multi-ArUco metric registration.
   ArUco is used only after COLMAP reconstruction.
   GT is used only for final evaluation.

Source policy:
- Use only method-final AP03 files.
- For AP03-SINGLE-REF14, prefer AP03_FINAL_SINGLE_REF14_RESULT.csv.
- For AP03-MULTI-ARUCO, prefer AP03_FINAL_MULTI_ARUCO_RESULT.csv.
- Reject copied duplicate hashes unless the duplicate is the validated baseline source.
- Reject AP03 rows if the selected COLMAP model is incomplete for the four-camera rig.
- Reject intermediate repo_like/ref_aruco debug files unless explicitly promoted to final source.
- Do not use GT for method fitting; GT is evaluation-only.

Current RES status:
- AP03-MULTI-ARUCO is accepted for 640x360, 960x540, and 1280x720_baseline.
- AP03-MULTI-ARUCO is excluded for 320x180_extreme and 1920x1080.
- AP03-SINGLE-REF14 is currently source-backed for 1280x720_baseline.
- AP03-SINGLE-REF14 for the other RES variants requires source recovery or rerun before being included numerically.
