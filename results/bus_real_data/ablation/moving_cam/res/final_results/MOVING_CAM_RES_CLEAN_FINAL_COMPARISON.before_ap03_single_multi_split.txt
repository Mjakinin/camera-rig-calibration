Compact interpretation:
- AP03 is best where valid: 640x360 = 2.822 cm / 0.405 deg, 960x540 = 3.213 cm / 0.140 deg, 1280x720 = 1.287 cm / 0.162 deg.
- AP03 is explicitly excluded at 320x180 and 1920x1080 because the selected COLMAP model is incomplete for the four-camera rig.
- AP01 is available for all resolutions and remains around 9-13 cm translation error, but it is a relative camera-map evaluation, not absolute world-pose estimation.
- AP02 is available for all resolutions but is more resolution-sensitive, with the best mean translation error at 960x540.

Reusable finalization workflow:
1. Run each AP method per ablation variant and freeze the method outputs.
2. Build a source-gated row set: only method-final, variant-specific files are accepted; copied hashes and intermediate files are rejected.
3. For rejected method/variant combinations, keep a row with status EXCLUDED and a precise reason.
4. Write exactly one final TXT into the ablation final_results folder.
5. Clean the ablation result folder so only final_results/<FINAL_TXT> remains.
